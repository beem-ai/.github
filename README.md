# beem-ai/.github

Organization-wide defaults for [beem-ai](https://github.com/beem-ai).

- `profile/README.md`: the landing page shown at github.com/beem-ai.
- `SECURITY.md`, `CONTRIBUTING.md` and `.github/ISSUE_TEMPLATE/`: defaults for every repository in the organization that does not have its own copy.
- `social-previews/`: 1280×640 link-preview images for each repository. Upload one under the repository's Settings > General > Social preview.

The profile links point at `beemotion.app`. Switch them to `beemotion.ai` when the site moves.
