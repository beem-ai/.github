# Security policy

Please do not report security vulnerabilities in public issues, pull requests or discussions.

Report them privately through GitHub: open the affected repository's **Security** tab and choose **Report a vulnerability**. If private reporting is not available, email [info@beemotion.ai](mailto:info@beemotion.ai) with "Security" in the subject. Include the steps to reproduce, the impact you expect, and any `x-request-id` values from affected API calls.

This covers the code in the [beem-ai](https://github.com/beem-ai) repositories and the BeEmotion API at `api.beemotion.app`. We will acknowledge your report, keep you updated while we fix it, and credit you when the fix ships if you would like.
