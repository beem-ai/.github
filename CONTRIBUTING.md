# Contributing

Thanks for helping improve BeEmotion's open-source projects.

## Issues

- Search the existing issues before you open a new one.
- For a bug, include what you ran, what you expected, what happened, and your SDK or tool version. For API problems, include the `x-request-id` header from the response.
- Never paste API keys (`be_live_...`) into an issue. Revoke any key that was exposed and create a new one.
- Report security problems privately, as described in [SECURITY.md](SECURITY.md).

## Pull requests

- For anything bigger than a small fix, open an issue first so we can agree on the approach.
- Keep each pull request to one change, and follow the style of the code around it.
- Run the repository's checks before you push. Each repository's README lists them.
- Add or update tests and docs to match your change.

## Help with the API

Start with [docs.beemotion.app](https://docs.beemotion.app). The [Errors](https://docs.beemotion.app/guides/errors) and [Rate limits](https://docs.beemotion.app/guides/rate-limits) guides cover the most common questions.
